# Changelog

## 1.0.0

Initial public release of **SwiftBlock**.

- Manifest V3 Chrome extension (Load unpacked)
- DOM keyword scan + `MutationObserver` to hide feed/article/card nodes
- Popup: enable/disable, add/remove keywords, reset defaults
- Settings persisted with `chrome.storage.sync`
- Default keywords cover names/aliases, Eras Tour, Taylor’s Version, and distinctive album/song titles
